## ✨ New Features

### Greet anyone from the command line

`greet` prints a friendly greeting for the name you give it, or for the world if you don't give one.

```sh
greet Ada
# Hello, Ada!
```

### Shout when you need to

Add `--shout` to print the greeting in capital letters. (#1)

```sh
greet --shout Ada
# HELLO, ADA!
```

Download `greet` for Linux or macOS, on Intel or Apple silicon, from the files below. Check a download with `gh attestation verify <file> --repo fabricahq/release-planner-sandbox`.
